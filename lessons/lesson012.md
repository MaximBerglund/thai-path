# Lesson 12 – Before, After, If & Then

## Learning Objectives

After this lesson you'll be able to:

- Say what happens before and after another event.
- Say what happens if something occurs.
- Build simple if/then sentences.
- Describe a sequence of events.
- Say "first", "then", and "finally".
- Express "since", "from", and "until".
- Use "when" and "while" to connect ideas.
- Understand expressions such as "last week", "last month", and "last year".

---

# Grammar

## Rule #51 – ก่อน (gɔ̀ɔn): before / first

ก่อน  
**gɔ̀ɔn**  
means "before" or "first".

One useful pattern is:

**Verb + ก่อน (gɔ̀ɔn)**  
= do something first

Example:

ผมกินข้าวก่อน  
**phǒm gin khâao gɔ̀ɔn**  
I'll eat first.

ก่อน can also introduce something that happens before another action.

ผมอาบน้ำก่อนเข้านอน  
**phǒm àap náam gɔ̀ɔn khâo naawn**  
I shower before going to bed.

ก่อนทำงาน ผมดื่มกาแฟ  
**gɔ̀ɔn tham ngaan, phǒm dèum gaa-faae**  
Before working, I drink coffee.

A useful everyday expression is:

ไปก่อนนะครับ  
**bpai gɔ̀ɔn ná khráp**  
I'll get going / I'll leave first.

---

## Rule #52 – หลังจาก (lǎng jàak): after

หลังจาก  
**lǎng jàak**  
means "after".

Pattern:

**หลังจาก + Action/Event, Main Sentence**

Examples:

หลังจากกินข้าว ผมดื่มกาแฟ  
**lǎng jàak gin khâao, phǒm dèum gaa-faae**  
After eating, I drink coffee.

หลังจากทำงาน ผมกลับบ้าน  
**lǎng jàak tham ngaan, phǒm glàp bâan**  
After work, I go home.

Compare:

ก่อนกินข้าว ผมดื่มน้ำ  
**gɔ̀ɔn gin khâao, phǒm dèum náam**  
Before eating, I drink water.

หลังจากกินข้าว ผมดื่มกาแฟ  
**lǎng jàak gin khâao, phǒm dèum gaa-faae**  
After eating, I drink coffee.

So:

- ก่อน (gɔ̀ɔn) = before
- หลังจาก (lǎng jàak) = after

---

## Rule #53 – ก่อนที่จะ (gɔ̀ɔn thîi jà): before doing...

A fuller structure you may encounter is:

ก่อนที่จะ...  
**gɔ̀ɔn thîi jà...**  
before...

Example:

ก่อนที่จะไปทำงาน ผมดื่มกาแฟ  
**gɔ̀ɔn thîi jà bpai tham ngaan, phǒm dèum gaa-faae**  
Before going to work, I drink coffee.

In everyday Thai, the shorter form is often enough:

ก่อนไปทำงาน  
**gɔ̀ɔn bpai tham ngaan**  
before going to work

You do not need to use ก่อนที่จะ (gɔ̀ɔn thîi jà) in every sentence.

---

## Rule #54 – ถ้า (thâa): if

ถ้า  
**thâa**  
means "if".

Pattern:

**ถ้า + Condition, Result**

Examples:

ถ้าฝนตก ผมอยู่บ้าน  
**thâa fǒn dtòk, phǒm yùu bâan**  
If it rains, I stay home.

ถ้าคุณพูดช้า ผมเข้าใจ  
**thâa khun phûut cháa, phǒm khâo-jai**  
If you speak slowly, I understand.

ถ้าผมหิว ผมกินข้าว  
**thâa phǒm hǐu, phǒm gin khâao**  
If I'm hungry, I eat.

---

## Rule #55 – ถ้า...ก็... (thâa...gâw...): if...then...

Thai often adds:

ก็  
**gâw**  
then / also / so

to the result clause.

Pattern:

**ถ้า X ก็ Y**  
**thâa X gâw Y**  
If X, then Y.

Example:

ถ้าฝนตก ผมก็อยู่บ้าน  
**thâa fǒn dtòk, phǒm gâw yùu bâan**  
If it rains, then I stay home.

ถ้าคุณพูดช้า ผมก็เข้าใจ  
**thâa khun phûut cháa, phǒm gâw khâo-jai**  
If you speak slowly, then I understand.

The ก็ (gâw) is often optional.

Both of these are possible:

ถ้าฝนตก ผมอยู่บ้าน  
**thâa fǒn dtòk, phǒm yùu bâan**  
If it rains, I stay home.

ถ้าฝนตก ผมก็อยู่บ้าน  
**thâa fǒn dtòk, phǒm gâw yùu bâan**  
If it rains, then I stay home.

---

## Rule #56 – Combining ถ้า (thâa) with can, must and should

The grammar from Lesson 11 combines naturally with ถ้า (thâa).

ถ้าคุณไม่เข้าใจ คุณถามได้ครับ  
**thâa khun mâi khâo-jai, khun thǎam dâai khráp**  
If you don't understand, you can ask.

ถ้าคุณเหนื่อย คุณควรพัก  
**thâa khun nʉ̀ai, khun khuan phák**  
If you're tired, you should rest.

ถ้าผมต้องทำงาน ผมไปไม่ได้  
**thâa phǒm dtông tham ngaan, phǒm bpai mâi dâai**  
If I have to work, I can't go.

---

## Rule #57 – แล้วก็ (láew gâw): and then / and also

แล้วก็  
**láew gâw**  
means "and then" or "and also".

Examples:

ผมตื่น แล้วก็อาบน้ำ  
**phǒm dtʉ̀ʉn, láew gâw àap náam**  
I wake up and then shower.

เรากินข้าว แล้วก็ไปตลาด  
**rao gin khâao, láew gâw bpai dtà-làat**  
We eat and then go to the market.

This is very common in spoken Thai.

---

## Rule #58 – Sequencing a story

Three useful expressions are:

ก่อนอื่น  
**gɔ̀ɔn ʉ̀ʉn**  
first / first of all

จากนั้น  
**jàak nán**  
after that / then

สุดท้าย  
**sùt-tháai**  
finally / last

Example:

ก่อนอื่น เรากินข้าว  
**gɔ̀ɔn ʉ̀ʉn, rao gin khâao**  
First, we eat.

จากนั้น เราไปตลาด  
**jàak nán, rao bpai dtà-làat**  
Then we go to the market.

สุดท้าย เรากลับบ้าน  
**sùt-tháai, rao glàp bâan**  
Finally, we go home.

This gives you a simple framework for telling a story:

**ก่อนอื่น → จากนั้น → สุดท้าย**  
**gɔ̀ɔn ʉ̀ʉn → jàak nán → sùt-tháai**  
first → then → finally

---

## Rule #59 – ตั้งแต่ (dtâng-dtàe): since / from

ตั้งแต่  
**dtâng-dtàe**  
means "since" or "starting from".

Examples:

ผมอยู่ที่นี่ตั้งแต่ปีที่แล้ว  
**phǒm yùu thîi-nîi dtâng-dtàe bpii thîi-láew**  
I've been here since last year.

ผมทำงานตั้งแต่เช้า  
**phǒm tham ngaan dtâng-dtàe cháao**  
I've been working since the morning.

Think:

**ตั้งแต่ X (dtâng-dtàe X)**  
= starting from X / since X

---

## Rule #60 – ที่แล้ว (thîi-láew): last / previous

When ที่แล้ว (thîi-láew) follows a unit of time, it refers to the previous one.

Examples:

อาทิตย์ที่แล้ว  
**aa-thít thîi-láew**  
last week

เดือนที่แล้ว  
**dʉan thîi-láew**  
last month

ปีที่แล้ว  
**bpii thîi-láew**  
last year

Compare this with แล้ว (láew) by itself:

ผมกินแล้ว  
**phǒm gin láew**  
I've already eaten.

Useful distinction:

- แล้ว (láew) = already / then
- [time period] + ที่แล้ว (thîi-láew) = last / previous [time period]

Also compare:

เดือนที่แล้ว  
**dʉan thîi-láew**  
last month

เดือนนี้  
**dʉan níi**  
this month

เดือนหน้า  
**dʉan nâa**  
next month

ปีที่แล้ว  
**bpii thîi-láew**  
last year

ปีนี้  
**bpii níi**  
this year

ปีหน้า  
**bpii nâa**  
next year

---

## Rule #61 – ตั้งแต่...จนถึง... (dtâng-dtàe...jon thʉ̌ng...): from...until...

จนถึง  
**jon thʉ̌ng**  
means "until / up to".

Together:

**ตั้งแต่ X จนถึง Y**  
**dtâng-dtàe X jon thʉ̌ng Y**  
from X until Y

Example:

ผมทำงานตั้งแต่เก้าโมงเช้าจนถึงห้าโมงเย็น  
**phǒm tham ngaan dtâng-dtàe gâo moong cháao jon thʉ̌ng hâa moong yen**  
I work from 9 a.m. until 5 p.m.

NOTE:

Thai has its own system for telling time, so expressions such as:

เก้าโมงเช้า  
**gâo moong cháao**  
9:00 a.m.

and:

ห้าโมงเย็น  
**hâa moong yen**  
5:00 p.m.

will be taught properly in a future dedicated lesson on telling time and days of the week.

---

## Rule #62 – จนกว่า (jon gwàa): until something happens

When "until" introduces an event or clause, you may encounter:

จนกว่า  
**jon gwàa**  
until

Example:

รอจนกว่าผมจะกลับครับ  
**rɔɔ jon gwàa phǒm jà glàp khráp**  
Wait until I come back.

This is slightly more advanced.

For now, focus on recognizing the pattern.

---

## Rule #63 – ทันที (than-thii): immediately

ทันที  
**than-thii**  
means "immediately / right away".

Examples:

ผมจะไปทันที  
**phǒm jà bpai than-thii**  
I'll go immediately.

หลังจากกินข้าว ผมกลับบ้านทันที  
**lǎng jàak gin khâao, phǒm glàp bâan than-thii**  
After eating, I go home immediately.

---

## Rule #64 – เมื่อ (mʉ̂a) and ตอนที่ (dtaawn thîi): when

เมื่อ  
**mʉ̂a**  
can mean "when" when introducing an event.

Example:

เมื่อผมถึงบ้าน ผมจะโทรหาเขา  
**mʉ̂a phǒm thʉ̌ng bâan, phǒm jà thoo hǎa khǎo**  
When I get home, I'll call him/her.

In everyday spoken Thai, you will also hear:

ตอนที่  
**dtaawn thîi**  
when / at the time that

Example:

ตอนที่ผมอยู่ประเทศไทย ผมกินอาหารไทยทุกวัน  
**dtaawn thîi phǒm yùu bprà-thêet Thai, phǒm gin aa-hǎan Thai thúk wan**  
When I'm in Thailand, I eat Thai food every day.

Useful beginner distinction:

- เมื่อ (mʉ̂a) = when
- ตอนที่ (dtaawn thîi) = when / at the time that

---

## Rule #65 – ระหว่างที่ (rá-wàang thîi): while

ระหว่างที่  
**rá-wàang thîi**  
means "while".

Example:

ระหว่างที่ผมทำงาน ผมดื่มกาแฟ  
**rá-wàang thîi phǒm tham ngaan, phǒm dèum gaa-faae**  
While I'm working, I drink coffee.

---

## Rule #66 – ถ้า (thâa) vs เมื่อ (mʉ̂a)

These words express different ideas.

ถ้า  
**thâa**  
if

The event is conditional.

ถ้าฝนตก ผมไม่ไป  
**thâa fǒn dtòk, phǒm mâi bpai**  
If it rains, I won't go.

Maybe it will rain. Maybe it won't.

เมื่อ  
**mʉ̂a**  
when

The event is treated as something expected to happen.

เมื่อผมถึงบ้าน ผมจะโทรหาเขา  
**mʉ̂a phǒm thʉ̌ng bâan, phǒm jà thoo hǎa khǎo**  
When I get home, I'll call him/her.

So:

**ถ้า (thâa)** = if  
**เมื่อ (mʉ̂a)** = when

# Mini Dialogue – Making a Plan

A:

พรุ่งนี้คุณว่างไหมครับ  
**phrûng níi khun wâang mǎi khráp?**  
Are you free tomorrow?

B:

ว่างครับ  
**wâang khráp**  
Yes, I am.

A:

ถ้าคุณว่าง เราไปกินข้าวกันไหมครับ  
**thâa khun wâang, rao bpai gin khâao gan mǎi khráp?**  
If you're free, shall we go eat together?

B:

ได้ครับ  
**dâai khráp**  
Sure.

A:

ก่อนกินข้าว ผมต้องทำงานนิดหน่อย  
**gɔ̀ɔn gin khâao, phǒm dtông tham ngaan nít nɔ̀i**  
Before eating, I have to work a little.

B:

ไม่เป็นไรครับ แล้วเจอกันตอนเย็น  
**mâi bpen rai khráp, láew jəə gan dtaawn yen**  
No problem. See you in the evening.

# Build It Yourself 🧠

Start with:

ผมดื่มกาแฟ  
**phǒm dèum gaa-faae**  
I drink coffee.

Now transform it.

ก่อนทำงาน ผมดื่มกาแฟ  
**gɔ̀ɔn tham ngaan, phǒm dèum gaa-faae**  
Before work, I drink coffee.

หลังจากกินข้าว ผมดื่มกาแฟ  
**lǎng jàak gin khâao, phǒm dèum gaa-faae**  
After eating, I drink coffee.

ถ้าผมเหนื่อย ผมดื่มกาแฟ  
**thâa phǒm nʉ̀ai, phǒm dèum gaa-faae**  
If I'm tired, I drink coffee.

ตอนที่ผมทำงาน ผมดื่มกาแฟ  
**dtaawn thîi phǒm tham ngaan, phǒm dèum gaa-faae**  
When I'm working, I drink coffee.

ระหว่างที่ผมทำงาน ผมดื่มกาแฟ  
**rá-wàang thîi phǒm tham ngaan, phǒm dèum gaa-faae**  
While I'm working, I drink coffee.

# Thai Toolbox 🧰

## Before & After

ก่อน  
**gɔ̀ɔn**  
before / first

หลังจาก  
**lǎng jàak**  
after

---

## Conditions

ถ้า  
**thâa**  
if

ก็  
**gâw**  
then / so / also

ถ้า...ก็...  
**thâa...gâw...**  
if...then...

---

## Sequence

แล้วก็  
**láew gâw**  
and then

ก่อนอื่น  
**gɔ̀ɔn ʉ̀ʉn**  
first

จากนั้น  
**jàak nán**  
then / after that

สุดท้าย  
**sùt-tháai**  
finally

---

## Time Range

ตั้งแต่  
**dtâng-dtàe**  
since / from

จนถึง  
**jon thʉ̌ng**  
until / up to

ตั้งแต่...จนถึง...  
**dtâng-dtàe...jon thʉ̌ng...**

จนกว่า  
**jon gwàa**

---

## Relative Time

ที่แล้ว  
**thîi-láew**  
last / previous

นี้  
**níi**  
this

หน้า  
**nâa**  
next

Examples:

อาทิตย์ที่แล้ว

last week

อาทิตย์นี้  
**aa-thít níi**  
this week

อาทิตย์หน้า  
**aa-thít nâa**  
next week

---

# Five High-Priority Patterns

## 1

**ก่อน + Verb**  
**gɔ̀ɔn + verb**  
before doing...

## 2

**หลังจาก + Verb**  
**lǎng jàak + verb**  
after doing...

## 3

**ถ้า X, Y**  
**thâa X, Y**  
if X, Y

## 4

**ถ้า X ก็ Y**  
**thâa X gâw Y**  
if X, then Y

## 5

**ตั้งแต่ X จนถึง Y**  
**dtâng-dtàe X jon thʉ̌ng Y**  
from X until Y
