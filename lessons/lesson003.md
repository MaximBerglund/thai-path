# Lesson 3 – Time and Tense

## Grammar

### Rule #5 – Thai verbs never change

Unlike English, Thai does not conjugate verbs.

Instead, time is shown using separate words.

Example:

ผมกินข้าว

I eat rice.

ผมกินข้าวเมื่อวาน

I ate rice yesterday.

Notice that กิน never changes.

---

### Rule #6 – Future

Use จะ before the verb.

Example:

ผมจะไปบ้าน

I'll go home.

---

### Rule #7 – Present Continuous

Use กำลัง before the verb.

Example:

ผมกำลังดื่มกาแฟ

I'm drinking coffee.

---

### Rule #8 – Already

Use แล้ว after the action.

Example:

ผมกินข้าวแล้ว

I've already eaten.

# Example Sentences

| Thai | Romanization | English |
|------|--------------|----------|
| ผมกินข้าววันนี้ | phǒm gin kâao wan níi | I eat rice today. |
| ผมกินข้าวเมื่อวาน | phǒm gin kâao mʉ̂a waan | I ate rice yesterday. |
| ผมจะกินข้าวพรุ่งนี้ | phǒm jà gin kâao phrûng níi | I'll eat rice tomorrow. |
| ผมกำลังดื่มกาแฟ | phǒm gamlang dèum gaa-faae | I'm drinking coffee. |
| ผมกินข้าวแล้ว | phǒm gin kâao láew | I've already eaten. |
| คุณจะพูดภาษาไทยไหม | khun jà phûut phaa-sǎa Thai mǎi? | Will you speak Thai? |
| ผมจะพูดภาษาไทย | phǒm jà phûut phaa-sǎa Thai | I'll speak Thai. |
| ผมกำลังเรียนภาษาไทย | phǒm gamlang rian phaa-sǎa Thai | I'm learning Thai. |

# Mini Dialogue

A:

คุณกำลังทำอะไร

I'm learning Thai.
